# مصادر فيلم الواجهة (28 ت1 2026)

مولّدة بالذكاء الاصطناعي عبر Figma Weave (طلب عمار: «العلبة… بدي أعملها واقعية تماماً»).

| الملف | شو هو | النموذج |
|---|---|---|
| `k0_ai_v1.jpg` | العلبة مسكّرة | Nano Banana Pro (تعديل لقطة الواجهة القديمة) |
| `k1_ai_v1.jpg` | العلبة مفتوحة وفيها ورق أبيض | Nano Banana Pro |
| `k2_ai_v2.jpg` | القطع المطبوعة مفرودة (بعد تنظيف الكتابة الصغيرة) | Nano Banana Pro |
| `k3_ai_v1.jpg` | العلبة على خلفية كحلية (ما انستخدمت) | Nano Banana Pro |
| `k4_ai_v1.jpg` | العلبة بالكيس على الكحلي | Nano Banana Pro |
| `v1.mp4` | الغطا بينفتح (k0 ← k1) | Kling O1 Pro، أول وآخر لقطة |
| `v2.mp4` | القطع بتطلع وبتنفرد (k1 ← k2) | Kling O1 Pro، أول وآخر لقطة |
| `v2_edit.mp4` | v2 بعد قص الثواني 2.2–4.0 (الشعار كان يتخربط فيها) ومزج ناعم | ffmpeg |

مقطع العلبة ← الكيس (k3 ← k4) طلع فيه الشعار مقلوب ومخربط، فانلغى؛ مكانه لقطة k4 مع حركة كاميرا بطيئة بالمتصفح.

إعادة توليد الإطارات:
```
python3 tools/reel_frames.py assets/reel-v1 source/reel-v1/v1.mp4 source/reel-v1/v2_edit.mp4 source/reel-v1/k4_ai_v1.jpg --fps 14
```
