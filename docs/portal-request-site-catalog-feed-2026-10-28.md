# طلب للبوابة: ملف أسعار ومنتجات الموقع الجديد (28 ت1 2026)

> **من:** محادثة الموقع (أدرك). **لـ:** محادثة نظام مدارك الداخلي (البوابة).
> **السبب:** الموقع صار ثابت بدون ووردبريس (`madarekmatbaa-bit/madarek-site`). عمار بدو المنتجات والأسعار تجي من البوابة، مصدر واحد بدل تعديل الموقع لحاله.
> **الحالة:** طلب، لسا ما انطبق.

## المرحلة 1: الأسعار بس (الأولوية)
رابط للقراءة فقط، بدون تسجيل دخول، بيرجع JSON بأسعار الموقع:

```
GET https://portal.madarekmatbaa.net/api/public/site-prices.json
{
  "generated_at": "2026-10-28T10:00:00Z",
  "currency": "USD",
  "items": [
    {"sku": "MD-AG-0001-01-200", "model": "MD-AG-0001", "price": 688.00, "regular": 688.00, "active": true},
    {"sku": "MD-TR-1-0661", "model": "MD-TR-1-0661", "price": 7.19, "regular": 7.19, "active": true}
  ]
}
```
- **sku:** نفس كود التنويعة يلي على الموقع (الموقع فيه 807 منتج و1,258 تنويعة؛ لكل واحد SKU).
- **price:** سعر الموقع النهائي بعد قاعدة كل مورد (مثلاً إيلبن = سعر البوابة الأساسي، وباقي الموردين حسب القاعدة المعتمدة). الموقع ما بيحسب شي، بس بيعرض.
- **regular:** إذا في خصم، السعر قبل الخصم؛ وإلا نفس price.
- **active=false:** المنتج انخفى من الموقع (متل موديلات إيلبن يلي انشالت).
- بلا كلفة، بلا حد أدنى للمندوب، بلا أي بيانات داخلية.

الموقع بيقرأ هالملف وقت البناء ويحدّث الأسعار والجداول («من $…»، صندوق السعر حسب الخيار، فيد جوجل وميتا).

## المرحلة 2: المنتجات كاملة (بعدين)
نفس الرابط بس فيه المنتج كامل: الاسم، الرابط (slug الحالي بالحرف، ممنوع يتغير)، الأقسام، الصور، الوصف المختصر والطويل، عنوان ووصف السيو، الخيارات (الاسم، القيم، الافتراضي)، وكل تنويعة بخياراتها وسعرها. هيك منتج جديد بالبوابة بيطلع عالموقع لحاله.

## إعادة بناء الموقع لما تتغير الأسعار
- الأبسط: الموقع بيعيد البناء كل يوم الصبح ويقرأ الملف.
- الأسرع: البوابة بتنادي «Deploy hook» تبع Cloudflare Pages بعد أي تعديل أسعار (رابط سري بيعطيه عمار من لوحة Cloudflare، ما بينحفظ إلا بإعدادات البوابة).

## للتحقق بعد التطبيق
- عينة: MD-AG-0001-01-200 = 688 على الموقع الحالي، MD-TR-1-0661 = 7.19، MD-TR-1-0185 = 9.04.
- عدد العناصر = عدد التنويعات المنشورة.
