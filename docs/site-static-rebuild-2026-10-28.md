## الفكرة
موقع ثابت (ملفات HTML جاهزة) بدل ووردبريس + ووكومرس + Woodmart + Elementor. نفس الروابط بالحرف، ونفس عناوين السيو والوصف والـ canonical والـ schema (منسوخة من الصفحات الحية)، ونفس أسماء ملفات الـ sitemap.

- **الكود:** GitHub `madarekmatbaa-bit/madarek-site` (خاص).
- **البناء:** `pip install -r requirements.txt && python3 build.py` ← يطلع مجلد `dist/`.
- **الاستضافة:** Cloudflare Pages (مجاني)، مشروع `madarek-site`، مربوط بالمستودع (فرع `main`، مجلد الناتج `dist`). أي تعديل بينرفع على `main` بيعيد البناء والنشر لحاله بدقيقتين تقريباً.
- **رابط المعاينة:** https://madarek-site.pages.dev (عليه `X-Robots-Tag: noindex` فما بينفهرس بجوجل).

## التصميم الجديد
- هيدر واحد نظيف بدل الشريط الكحلي + الهيدر: الشعار، القائمة، بحث ظاهر بنتائج مباشرة، زر «اطلب عرض سعر».
- قائمة «المنتجات» صارت قائمة كبيرة (Mega menu) بكل الأقسام والأقسام الفرعية وصورة القسم.
- صفحات الأقسام: عنوان كبير، شريط الأقسام الرئيسية، أقسام فرعية بصور صغيرة، بحث داخل القسم، ترتيب، بطاقات أبسط («من $684»).
- صفحة المنتج: معرض صور كبير، الخيارات كأزرار، صندوق السعر حسب الاختيار، زر واتساب واحد + رابط مبيعات سوريا، ثلاث نقاط ثقة (الكود، البروفة قبل الطباعة، الشحن)، والوصف/الخيارات والأسعار/المواصفات كأقسام بفهرس جانبي.
- فوتر جديد: أرقام المبيعات حسب السوق، الأقسام، ملفات التحميل، السياسات وبوابة الموظفين.
- الخطوط: IBM Plex Sans Arabic + Poppins للأرقام والإنجليزي (حسب دليل الهوية). أيقونات Phosphor.
- صفحات المحتوى القديمة (الرئيسية، من نحن، الأسواق…) نفس محتواها، مع توحيد العرض والمسافات.
- **واجهة الرئيسية (28 ت1، طلب عمار «بدي العلبة واقعية تماماً»):** بدل العلبة المرسومة، صار في فيلم واقعي بيمشي إطار إطار مع نزول الصفحة: العلبة مسكّرة، ثم الغطا بينفتح، ثم القطع بتطلع وبتنفرد مع أسماءها وأوزان ورقها، ثم دائرة كحلية بتفتح على العلبة بالكيس. الصور والمقاطع مولّدة بالذكاء الاصطناعي (Nano Banana Pro وKling عبر Figma Weave، كلفة 242 رصيد Weave)، والكتابة كلها نص حي (نفس الـ H1 والروابط).
  - الحجم: ~1.7MB للكمبيوتر و~1.3MB للموبايل، وبتنزل بعد ما تخلص الصفحة. أول إطار صورة عادية (بيظهر فوراً وبدون JavaScript)، ومع «تقليل الحركة» بيصير تبديل ناعم بدل الفيلم.
  - المصادر وطريقة إعادة التوليد: `source/reel-v1/README.md`. مقطع «العلبة بتفوت بالكيس» انلغى لأن الشعار تخربط فيه، ومكانه لقطة الكيس مع حركة كاميرا بطيئة.
  - فرع `ai-ref` على GitHub مؤقت (صور مرجعية للتوليد)، بينحذف بعد الاعتماد.

## فحص المعاينة والسيو (28 ت1)

- **مقارنة سيو مع الموقع الحي لكل الـ 881 رابط:** العنوان، الوصف، robots، canonical، og:title/description/url/image/type، twitter، أنواع الـ schema، hreflang، prev/next: **كلها متطابقة**. الفرق الوحيد: صفحتي سياسة الإرجاع والخصوصية صار إلهن H1 (الحي ما فيه)، وهاد تحسين.
- **بعد التحويل:** www هو العنوان الأساسي (متل اليوم)، والجذر بيحوّل لـ www، وكل شي على https، والدوت نت بيحوّل 301 للدوت كوم. منرجع نبعت الـ sitemap بـ Search Console ومنراقب تقرير الصفحات شهر.
- **ملاحظة:** `app.madarekmatbaa.net` (الفريق التاني) مفتوح لجوجل وبينافس الموقع؛ المطلوب `noindex`.
