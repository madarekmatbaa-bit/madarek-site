## الفكرة
موقع ثابت (ملفات HTML جاهزة) بدل ووردبريس + ووكومرس + Woodmart + Elementor. نفس الروابط بالحرف، ونفس عناوين السيو والوصف والـ canonical والـ schema (منسوخة من الصفحات الحية)، ونفس أسماء ملفات الـ sitemap.

- **الكود:** GitHub `madarekmatbaa-bit/madarek-site` (خاص).
- **البناء:** `pip install -r requirements.txt && python3 build.py` ← يطلع مجلد `dist/`.
- **الاستضافة المخططة:** Cloudflare Pages (مجاني) مربوط بالمستودع.

## التصميم الجديد
- هيدر واحد نظيف بدل الشريط الكحلي + الهيدر: الشعار، القائمة، بحث ظاهر بنتائج مباشرة، زر «اطلب عرض سعر».
- قائمة «المنتجات» صارت قائمة كبيرة (Mega menu) بكل الأقسام والأقسام الفرعية وصورة القسم.
- صفحات الأقسام: عنوان كبير، شريط الأقسام الرئيسية، أقسام فرعية بصور صغيرة، بحث داخل القسم، ترتيب، بطاقات أبسط («من $684»).
- صفحة المنتج: معرض صور كبير، الخيارات كأزرار، صندوق السعر حسب الاختيار، زر واتساب واحد + رابط مبيعات سوريا، ثلاث نقاط ثقة (الكود، البروفة قبل الطباعة، الشحن)، والوصف/الخيارات والأسعار/المواصفات كأقسام بفهرس جانبي.
- فوتر جديد: أرقام المبيعات حسب السوق، الأقسام، ملفات التحميل، السياسات وبوابة الموظفين.
- الخطوط: IBM Plex Sans Arabic + Poppins للأرقام والإنجليزي (حسب دليل الهوية). أيقونات Phosphor.
- صفحات المحتوى القديمة (الرئيسية، من نحن، الأسواق…) نفس محتواها، مع توحيد العرض والمسافات.

## الحجم
- صفحة المنتج ~22KB مضغوطة، صفحة القسم ~14KB، CSS ~22KB، JS ~16KB (بدل عشرات ملفات ووردبريس وjQuery).

## الخطوات الجاية
1. إكمال سجلات .com على Cloudflare.
2. ربط Cloudflare Pages بالمستودع (عمار بيوافق على صلاحية GitHub) ← رابط معاينة `*.pages.dev` (عليه noindex).
3. مقارنة ومراجعة، ثم تغيير الـ Nameservers، ثم توجيه www.madarekmatbaa.com لـ Pages.
4. HostGator يضل شهر احتياط.
5. ربط المنتجات والأسعار بالبوابة (مصدر واحد).
