## Addresses
| | Arabic (source) | English | Turkish |
|---|---|---|---|
| Home | `/` | `/en/` | `/tr/` |
| All products | `/shop/` | `/en/shop/` | `/tr/urunler/` |
| Category | `/product-category/…/` | `/en/category/<english slugs>/` | `/tr/kategori/<turkish slugs>/` |
| Product | `/product/<arabic slug>/` | `/en/product/<english slug>/` | `/tr/urun/<turkish slug>/` |
| Pages | `/about-us/`, `/markets/مطبعة-في-الخليج/` … | `/en/about-us/`, `/en/markets/printing-in-the-gulf/` … | `/tr/hakkimizda/` … |
| Search | `/search/` | `/en/search/` | `/tr/arama/` |

Slugs are written once to `data/i18n/slugs.json` and never change after that (a better translation later
does not move the URL). Edit that file by hand only before a page is first published.

## How it works (`lib/i18n.py`)
1. `build.py` builds the Arabic site as before.
2. Each Arabic page is parsed; every block's text is looked up in the translation memory
   (`data/i18n/en.json`, `data/i18n/tr.json`). Inline tags travel as markers (⟦1⟧…⟦/1⟧), codes, prices and
   numbers as ⟨0⟩, so one translation serves every product with the same wording.
3. Links point to the same page in the language, `lang`/`dir` switch to `en`/`tr` + `ltr`, canonical,
   `hreflang` (ar, en, tr, x-default = Arabic) and `og:locale` are set, JSON-LD is translated.
4. Contacts: one rep per language. English shows only Ms. Heba (+90 551 005 90 96); Turkish only Ali
   (+90 507 114 63 77). Other reps' cards and the «Syria sales» buttons are removed; every WhatsApp link and
   its prefilled message are translated and sent to the language's rep.
5. Text without a translation is listed in `data/i18n/missing-<lang>.json` and stays Arabic (marked
   `lang="ar"`) until translated. A product or page whose **name** is not translated yet is not published in
   that language at all.
6. Per-language search index (`/en/data/catalog.json`), sitemaps (`en-sitemap.xml`, `tr-sitemap.xml` in the
   sitemap index) and 404 pages (`/en/404.html`, `/tr/404.html`).
7. `data/i18n/overrides.json`: hand-written titles/descriptions per language (English pages written for Gulf
   buyers: UAE, Saudi Arabia, Qatar, Kuwait, Bahrain, Oman).

## Automatic translation of new Arabic text
`.github/workflows/translate.yml` runs on every push that changes content: build → `tools/translate.py api`
(Claude API) → build → commit the memory. **Needs the GitHub secret `ANTHROPIC_API_KEY`.** Without it the
workflow does nothing and new Arabic text waits (Arabic shown) until it is translated in a chat with Claude:
`python3 build.py` then `tools/translate.py export/check/import`.
Style guide and glossary for every translation: `tools/i18n_style.md`.
